# UC_PAD_cuadernos_Jupyter

Este repositorio reúne el trabajo práctico desarrollado durante la asignatura **Programación para Analítica de Datos** , como evidencia del aprendizaje en la materia.

## 📚 Contenido

### 💻 Python desde cero

**01 Python desde cero**
Cuaderno introductorio de programación en Python que trabaja variables, tipos de datos, operaciones aritméticas, conversiones de datos, comparaciones, cadenas formateadas y corrección de errores, mediante ejercicios prácticos y autoevaluaciones.

**02 Python desde cero — Lógica, colecciones y control**
Cuaderno enfocado en expresiones y conectores lógicos, listas, diccionarios, estructuras condicionales, ciclos `for` y `while`, funciones con parámetros y retorno, y ejercicios de resumen de información antes del uso de Pandas.

**Evaluaciones exportables**
Archivos generados a partir de las autoevaluaciones de los cuadernos de Python desde cero.

### 🐍 Fundamentos de programación Python

Ejercicios desarrollados a partir de las presentaciones PPTX compartidas en clase y las guías prácticas:

**Python I**
Paradigmas de programación, estructuras de control y estructuras repetitivas.

**Python II**
Listas, tuplas y diccionarios.

**Python III**
 Funciones, definición, parámetros y `return.

### 🔢 NumPy y Pandas

Ejercicios desarrollados a partir de las presentaciones PPTX compartidas en clase y las guías prácticas para la introducción y manejo de NumPy y Pandas 

### 📊 Cuadernos prácticos

**Cuaderno 01**
Caso práctico de lectura de archivos **CSV** y manipulación de datos con **Pandas**.

**Cuaderno 02**
Caso práctico de **ETL (extracción, transformación y carga)** utilizando **Pandas**.

**Cuaderno 03**
Caso práctico de aplicación de las herramientas de programación y análisis de datos trabajadas durante el curso.
